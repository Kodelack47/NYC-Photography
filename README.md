# NYC Photography

A multi-page website for a New York City photography studio, built with **HTML, CSS, and JavaScript**
(with Bootstrap and W3.CSS for layout).

## Pages

- **Home** (`index.html`): landing page with a photo slideshow
- **Exhibition** (`Exhibition.html`): gallery of prints you can add to a cart
- **Checkout** (`checkout.html`): cart summary
- **Contact** (`Contact.html`): contact form
- **Register / Login** (`user-reg.html`, `login.html`): account forms

## Features

- Image slideshow with next/previous controls and dot navigation (`script.js`)
- Shopping cart that adds items and tracks quantities (`NYCP.js`)
- Responsive layout

## Run it

Clone the repo and open `index.html` in your browser. No build step is needed.
